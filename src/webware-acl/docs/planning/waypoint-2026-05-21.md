### AclInterface + Acl simplification

- `isAllowed(UserInterface|null $user, string|ResourceInterface|null $resource, ?string $privilege): bool`
  — simplified from accepting string roles; null user always denies
- `isAllowedRoute(UserInterface|null $user, ResourceInterface $resource): bool`
  — fail-closed: unregistered resource → deny; calls `$this->isAllowed()` (not Laminas directly)
- `isAllowedByRouteName` — **REMOVED** from interface and implementation
- `$paramMap` — **REMOVED** from `Acl` constructor and `AclFactory`

### Role layer — new files in `src/webware-acl/src/Role/`

**`SingleRoleUserProxy`**
- Wraps `UserInterface $user` + `string $roleId`
- Implements full `UserInterface` contract
- `getRoleId()` returns the single role string (for Laminas registry lookup)
- All other methods delegate to the wrapped user (`getOwnerId`, `getDetails`, `getDetail`,
  `getIdentity`, `getResourceId`, `isGuest`)

**`UserRoleIterator`**
- Implements `Iterator<int, UserInterface>`
- Wraps a `UserInterface`; converts `getRoles()` to array on construction
- `current()` yields `new SingleRoleUserProxy($user, $roles[$position])`

**`Acl::isAllowed()` wired with `UserRoleIterator`**
- Iterates all roles via `UserRoleIterator`, calls Laminas `isAllowed($roleProxy, ...)` per role
- Returns `true` if any role passes, `false` if none do or user is null

### Navigation cascade

- **`NavigationFilterIterator`**: `string[] $roles` → `UserInterface|null $user`;
  `accept()` calls `$this->acl->isAllowed($this->user, $route->getName(), null)` — fail-closed
- **`Navigation` view helper**: `setRoles(string[])` → `setUser(UserInterface|null)`;
  `private array $roles` → `private ?UserInterface $user`; `resetState()` updated
- **`NavigationMiddleware`**: `setRoles([...$user->getRoles()])` → `setUser($user)`

### Admin widget cascade

- **`AclWidgetFilterIterator`**: `string[] $roles` → `UserInterface|null $user`;
  `accept()` calls `$this->acl->isAllowed($this->user, $widget->resourceId, $widget->privilege)`
- **`DashboardMiddleware`**: removed `$roles` unpacking; passes `$user` directly

## Key Design Decisions

- `isAllowed()` only ever receives `UserInterface|null` — no string/array role paths
- All paths (route auth, navigation, widgets) fail-closed — unregistered resource = deny
- `OwnershipAssertion` uses `ProprietaryInterface::getOwnerId()` for user-level ownership
- `StoreOwnedResourceAssertion` will use `StoreProprietaryInterface::getStoreId()` — no overloading `getOwnerId()`
- `SingleRoleUserProxy` lives in `webware-acl` — IMS layer extends it for store ownership
- `webware-usermanager`/`webware-acl` stay clean — no `ims-store` dependency
