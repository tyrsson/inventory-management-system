## Session Accomplishments

### Item 1 complete — RouteResource / Acl cleanup

- **`Acl::isAllowedRoute()`** — now passes `null` as privilege to `isAllowed()` instead of
  `$routeResource->getPrivilegeId()`. Authorization is resource-level only (route name), no
  privilege dimension.

- **`Acl::isAllowedRoute()` fail-closed comment** — the `return false` for unregistered routes
  was already intentional (user-set). The misleading "opt-in model / allow through" comment was
  replaced with an unambiguous block comment:
  ```
  // FAIL CLOSED — intentional, do not change to true.
  // Routes must be explicitly registered as ACL resources to be accessible.
  ```
  This is a **hard requirement**. Do not change, do not ask about it.

- **`RouteResource`** — `PrivilegeInterface` removed:
  - `use Webware\Acl\PrivilegeInterface` import removed
  - `PrivilegeInterface` removed from `implements` list
  - `getPrivilegeId()` method deleted
  - Docblock updated: "Privilege = HTTP method..." line replaced with
    "Role = authenticated UserInterface or default Guest from request attribute"

- **`PrivilegeInterface` file** — NOT deleted yet. Still used in:
  - `CommandBus/AuthorizableCommandInterface.php`
  - `ims-manifest/Listener/RegisterManifestRulesListener.php`
  - `webware-admin/Listener/RegisterAdminRulesListener.php`
  - `test/unit/PrivilegeTest.php`
  Deletion deferred to item 2 (deletion sweep), when the listeners using its constants
  are also removed.

### Verified via source trace
- Confirmed via Laminas ACL source that passing `null` privilege to both `allow()` and
  `isAllowed()` stores/matches rules under `rules['allPrivileges']` and the assertion
  **does run** — receiving `$privilege = null`. No privilege is required for assertions.

### Hard rule recorded in memory
- `/memories/repo/acl-hard-rules.md` created — documents the fail-closed behaviour and
  instructs the agent never to change or question it.
